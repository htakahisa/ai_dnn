# ファイル配置と実行ルール

## 適用範囲

- このルールは、`03.game` 配下で今後新規に作成するファイル・ディレクトリに適用する。
- 既存のファイル・ディレクトリは、現在の配置と実行方法のままでよい。このルールへの適合だけを目的とした移動や改名は行わない。
- 既存機能への追加でも、新規ファイルは用途に応じたディレクトリに配置する。
- 配下に個別の `AGENTS.md` がある場合は、そのディレクトリ固有の指示も確認する。

## 新しいAI・機能の配置

- 新しいAIなどを作成する場合は、専用ディレクトリを作成し、関連ファイルをその下にまとめる。
- AIのディレクトリ名は、AI名とバージョンがわかる名前にする。
- 例: `new_ai` の v1 を作成する場合は、`03.game/new_ai_v1/` を作成する。
- 新しいバージョンは、例として `new_ai_v2/` のように別ディレクトリへ配置する。
- `03.game` 直下に、新しいAI固有のファイルや出力を散在させない。

## 用途別の整理

- テストクラス・テストコードは `test/` に配置する。
- 学習データ、学習済みモデル、チェックポイントなどの学習関連ファイルは `data/` に配置する。
- ログファイルは `logs/` に配置する。
- 学習用のPythonスクリプトは、対象AIのディレクトリに配置する。学習スクリプトと、生成される学習データ・モデルは区別して整理する。
- AI固有のテスト・データ・ログは、そのAIのディレクトリ内の `test/`・`data/`・`logs/` にまとめる。
- ゲーム全体で共有するテスト・データ・ログは、`03.game/test/`・`03.game/data/`・`03.game/logs/` にまとめる。
- その他のファイルも、用途がわかるディレクトリに整理する。必要なディレクトリは作成時に用意する。

配置例:

```text
03.game/
├── AGENTS.md
├── test/                   # ゲーム全体のテスト
├── data/                   # ゲーム全体で共有するデータ
├── logs/                   # ゲーム全体のログ
└── new_ai_v1/
    ├── training_new_ai.py  # 学習スクリプト
    ├── learning_new_ai.py  # 推論などの関連コード
    ├── test/              # このAIのテスト
    ├── data/              # このAIの学習データ・モデル・チェックポイント
    └── logs/              # このAIのログ
```

## 学習スクリプトの実行ルート

- 新しく作成する学習スクリプトは、対象AIのディレクトリを作業ディレクトリ（カレントディレクトリ）として実行することを基本とする。
- 例: `03.game/new_ai_v1/training_new_ai.py` の実行ルートは、`03.game/new_ai_v1/` とする。
- データやログの入出力パス、インポートは、この実行方法で動作するように実装する。
- 共通コードを参照する場合も、対象AIのディレクトリから実行できるようにする。
- 実行方法を記載する場合は、作業ディレクトリと実行コマンドを明示する。

`03.game` から実行する場合の例:

```powershell
Set-Location new_ai_v1
python training_new_ai.py
```
