# ファイル配置と実行ルール

## 射線判定・シナリオ変更と学習済みモデルの互換性

- 2026-10-10 に壁の射線判定を変更した。`grid_lines.py` の `wall_line_cells()` は、角に接する隣接セルも含めて壁による遮蔽を判定する。識別子は `WALL_LOS_VERSION = 'symmetric_supercover_v1'`。既存の `line_cells()` とは用途が異なるため、変更時は呼び出し元を確認する。
- 射線判定やシナリオ設定の変更は、学習済みモデルの互換性に影響する。変更時には、観測・配置・シナリオ識別値・依存モデルへの影響を確認し、再学習が必要な範囲をユーザーに説明する。
- Touyama v3 で発生したチェックポイント不一致の詳細と対応手順は、`touyama_v3/AGENTS.md` を参照する。

## 設定とコマンドラインオプション

- 通常は、対象スクリプトをオプションなしで実行する。
- 学習回数、対象AI、入力データ、保存先、評価頻度、乱数seed、新規学習・再開など、通常使用する設定はスクリプト冒頭の名前付き定数にまとめる。
- 継続して使用する設定を、コマンドラインオプションだけで指定する実装や実行手順にしない。後からソースを見て設定を確認できるようにする。
- コマンドラインオプションは、検証や一時的な変更など、必要な場合にのみ定数を上書きする手段として残す。
- 実行手順には、定数を変更する場所、作業ディレクトリ、オプションなしの通常実行コマンドを明示する。
- この設定ルールは、新規スクリプトと既存スクリプトの変更時の両方に適用する。

## 適用範囲

- このルールは、`03.game` 配下で今後新規に作成するファイル・ディレクトリに適用する。
- 既存のファイル・ディレクトリは、現在の配置と実行方法のままでよい。このルールへの適合だけを目的とした移動や改名は行わない。
- 既存機能への追加でも、新規ファイルは用途に応じたディレクトリに配置する。
- 配下に個別の `AGENTS.md` がある場合は、そのディレクトリ固有の指示も確認する。

## 新しいAI・機能の配置

- 新しいAIなどを作成する場合は、専用ディレクトリを作成し、関連ファイルをその下にまとめる。
- AIのディレクトリ名は、AI名とバージョンがわかる名前にする。
- 例: `new_ai` の v1 を作成する場合は、`03.game/new_ai_v1/` を作成する。
- 新しいバージョンは、例として `new_ai_v2/` のように別ディレクトリへ配置する。
- `03.game` 直下に、新しいAI固有のファイルや出力を散在させない。

## 用途別の整理

- テストクラス・テストコードは `test/` に配置する。
- 学習データ、学習済みモデル、チェックポイントなどの学習関連ファイルは `data/` に配置する。
- ログファイルは `logs/` に配置する。
- 学習用のPythonスクリプトは、対象AIのディレクトリに配置する。学習スクリプトと、生成される学習データ・モデルは区別して整理する。
- AI固有のテスト・データ・ログは、そのAIのディレクトリ内の `test/`・`data/`・`logs/` にまとめる。
- ゲーム全体で共有するテスト・データ・ログは、`03.game/test/`・`03.game/data/`・`03.game/logs/` にまとめる。
- その他のファイルも、用途がわかるディレクトリに整理する。必要なディレクトリは作成時に用意する。

配置例:

```text
03.game/
├── AGENTS.md
├── test/                   # ゲーム全体のテスト
├── data/                   # ゲーム全体で共有するデータ
├── logs/                   # ゲーム全体のログ
└── new_ai_v1/
    ├── training_new_ai.py  # 学習スクリプト
    ├── learning_new_ai.py  # 推論などの関連コード
    ├── test/              # このAIのテスト
    ├── data/              # このAIの学習データ・モデル・チェックポイント
    └── logs/              # このAIのログ
```

## ファイル名称
- [PJの略称]_[機能]_[attaker/defender]_[詳細].py のように、わかりやすい名前にする。
例) tv4 project で、map のdata で、attacker の リテイク左サイト用の場合
 tv4_map_attacker_retake_L.py

例) tv4 project、学習、defender search 
tv4_train_defender_search.py

例) tv4 project、推論、attacker quard
tv4_learn_attacker_guard.py

など。完全に準拠できない場合は、機能、詳細部分をうまく利用してわかりやすいファイル名にすること。

## 学習スクリプトの実行ルート

- 新しく作成する学習スクリプトは、対象AIのディレクトリを作業ディレクトリ（カレントディレクトリ）として実行することを基本とする。
- 例: `03.game/new_ai_v1/training_new_ai.py` の実行ルートは、`03.game/new_ai_v1/` とする。
- データやログの入出力パス、インポートは、この実行方法で動作するように実装する。
- 共通コードを参照する場合も、対象AIのディレクトリから実行できるようにする。
- 実行方法を記載する場合は、作業ディレクトリと実行コマンドを明示する。

`03.game` から実行する場合の例:

```powershell
Set-Location new_ai_v1
python training_new_ai.py
```
