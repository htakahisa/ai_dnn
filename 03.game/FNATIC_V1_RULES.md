# Fnatic v1 — ルールベース初版

試合画面またはCompetitionのAI欄で **Fnatic v1** を選択してください。
ロスターは別設定です。Fnatic2023以外の5人でも利用できます。
アプリを起動し直すと新しい実装が読み込まれます。

実装は `fnatic_v1_rules.py`。学習モデルは読み込みません。
旧Fnatic v1の学習モデル・Fnatic v2のファイルは残しています。
旧v1は内部キー `fnatic_legacy_v1` から呼び出せます。

## 初版の動作

- 攻撃: 最短距離と観測済みの敵射線を基に設置目標を固定。
- キャリアー: 設置可能マスなら即設置。残り時間が最短移動＋設置時間＋10Tick以下なら、通常方針より最短設置を優先。
- 回収: スパイクが落ちたら最短距離の生存者を回収担当に固定。
- カバー: 近い2人をキャリアーの護衛担当とし、欠員時に再選出。
- ミクロ: 近くの味方の射線へ5Tick以内で参加できる場合、同じ敵を狙える位置へ移動。
- アビリティ: エントリー前にサイトへリコン、守備側進入方向へスモーク。接敵時にはフラッシュ。
- 守備: セットアップではA側2人、中央1人、B側2人を目標に合法セルへ配置。接敵時は静止。複数の観測敵やドロップスパイクへ増援。
- ポストプラント: スパイクと隣接解除セルへの射線を評価した位置へ移動して待機。
- リテイク: 解除地点へ接近し、スモーク担当は解除地点を隠す。隣接セルから解除。

厳密な隊列維持、複雑なスプリット／フェイク、相手別対策、過去ラウンド傾向の適応は未実装です。
距離3マスだけでは壁越しのカバーを保証しません。実戦のフィードバックに合わせて調整します。

## 確認コマンド

```powershell
D:\git\python\python.exe -m unittest test_fnatic_v1_rules -v
```

フィードバックには、攻守、ラウンド・Tick、キャリアー名、起きた動作と期待する動作を添えると原因を追いやすくなります。
