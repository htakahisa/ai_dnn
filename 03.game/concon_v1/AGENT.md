# cocon_v1 

## 基本方針
- 可能な限りコード、ドキュメントは分類してディレクトリに配置する。ただし、ディレクトリ階層が深くなりすぎたりして余計わかりにくい構造は避けること。
- テストコードは test ディレクトリ以下に配置すること
- ドキュメントはこの AGENT.md を除き docs 以下に配置すること。まとまりがよくなるなら、サブディレクトリ作成も行うこと。
- 学習用スクリプトの自動実行はしないこと。学習はこちらで手動で時間を見て行うため。
- token の消費はなるべく抑える形で対応したいので、出力、入力についてこちらで制御できる分については効率よく行うこと。特にログ出力などは必要なものをきちんと取得して対応すること。ただ、token消費を抑えるため、データが足りず調査に余計にtokenを使うような愚かな真似は許さない。
