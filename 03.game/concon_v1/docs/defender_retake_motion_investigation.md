# リテイクの到達・解除選択の診断

`diagnose_defender_retake.py` は重みを更新せず、保存したリテイク開始状態から相手AIも動かして行動を記録します。通常の実戦評価の開始条件 `EVAL_START_EPSILON` は変更しません。

`concon_v1` から `python diagnose_defender_retake.py` で実行します。既定では直近の学習実行の501〜600 episodeに含まれる失敗場面から、各AI・左右2件ずつ、計20件を選びます。各試合の探索率は元のログと同じ値です。latestとfoundationの双方を調べ、結果を `data/diagnostics/defender_retake_motion.json` に保存します。

診断ログは実際の位置からの到達判定と、IQ知覚に基づくDEFUSEの行動マスクを別に記録します。スパイクまでの実距離などの診断情報は、モデルの入力や行動選択には渡しません。各試合について到達したtick・残り時間・最大解除進捗、各判断について待機状態・基礎値の有効条件・選択行動・Q値を記録します。

## 今回の結果

今回のlatestは左右とも700 episode時点の保存済み重みです。501〜600 episodeの失敗場面20件を再現しました。全5種類の相手AIを含みます。固定した開始状態と探索率を使う診断であり、元の学習試合の完全再現や、全データでの正式評価ではありません。

| 指標 | latest | foundation |
| --- | ---: | ---: |
| 診断した試合 | 20 | 20 |
| 実際の解除距離まで到達した試合 | 4 | 2 |
| DEFUSEを選んだ試合 | 3 | 0 |
| 解除成功 | 1 | 0 |

latestでは4292判断中2584判断（60.2%）で移動・解除の基礎値が無効でした。敵の位置記憶があるため無効となる判断は2246回で、そのうち2147回は射撃可能な敵がいない判断でした。合流待ちによる無効は468回、基礎学習で未対応の位置による無効は202回です。無効理由は重複します。

実際に解除距離にいて、モデルのDEFUSEマスクも有効で、残り6 tick以上あった判断は18回でした。そのうち13回では最大Q値の行動がDEFUSE以外でした。射撃可能な敵がいない判断でも、5回はDEFUSE以外を最大Q値としていました。

例としてomoko_v1・Rサイトのある判断では、実際の解除距離内・残り21 tick・射撃可能な敵なし・合流待ちなしでしたが、敵の位置記憶があるため基礎値が無効となり、移動のQ値 -0.423 がDEFUSEのQ値 -0.962 を上回っていました。探索だけでは解除を選ばない問題を説明できません。

基礎値が有効で、目標へ近づく合法な行動があったlatestの1680判断でも、395回は最大Q値が近づく行動以外でした。foundationでは同条件の1090判断中1回でした。固定している基礎値に学習対象ネットワークの値を加算する構成なので、基礎値自体を固定しても、合算した行動の優先順位は変わります。この件数だけで各判断の良否は確定しませんが、静かな場面の移動の保持を確認する必要があります。

## 次の修正方針

追加で、同じ700 episode時点の重み・20場面・探索率について、基礎値の加算だけを外して比較しました。重みは1度読み込んで固定し、両条件で同じものを使用しました。結果は `data/diagnostics/defender_retake_foundation_ablation.json` に保存しました。

| 学習済みモデルの条件 | 到達した試合 | 解除を試した試合 | 解除成功 |
| --- | ---: | ---: | ---: |
| 基礎値を加算 | 4/20 | 3/20 | 1/20 |
| 同じ重みで基礎値を加算しない | 0/20 | 0/20 | 0/20 |

現在の学習済みモデルでは、基礎値が実際の到達に寄与しています。基礎を使わず最初から別の学習をした場合との比較ではありません。この診断結果からは、基礎を削除するより、その使用条件と戦闘学習中の基礎動作の保持を見直す方針が適切と考えます。

1. 射撃可能な敵がいない場面でも、敵の位置記憶だけで移動・解除の基礎値が無効になる条件を見直す。
2. 実戦の知覚・人数・障害物を含む状態で移動・解除の基礎を学習し、戦闘学習中にもその行動が崩れにくい補助学習を検討する。
3. 同じ診断場面で到達率、時間が足りる解除機会での選択、解除継続を再確認してから本学習を再開する。

## 修正後の確認

移動・解除の基礎値の使用条件を「敵の位置記憶なし」から「射撃可能な敵なし」に変更しました。合流待ちの場面では引き続き基礎値を加算しません。学習には、現在の合法な移動・待機・解除の優先順位を維持する補助損失を追加しました。向き・アビリティ・ウルトの教師値は指定しません。

同じ700 episodeの保存済み重み、同じ20場面、同じ探索率で使用条件の変更を確認しました。

| 指標 | 修正前 | 使用条件の修正後 |
| --- | ---: | ---: |
| 解除距離まで到達した試合 | 4/20 | 9/20 |
| DEFUSEを選んだ試合 | 3/20 | 7/20 |
| 解除成功 | 1/20 | 5/20 |

結果は `data/diagnostics/defender_retake_after_foundation_gate.json` に保存しました。この比較では重みを更新していないため、改善は基礎値の使用条件の変更によるものです。補助損失を使った本学習後の効果は、ユーザーが再学習した結果で確認します。補助損失については、合法性、交戦・合流待ちの除外、DEFUSEの優先順位への勾配、基礎値の固定、TD更新との組合せをテストしました。

診断は失敗場面から選んだ20件の比較であり、全データの性能保証ではありません。本学習は実行せず、保存済み重み・アビリティ定点・ゲームの報酬とルールは変更していません。
