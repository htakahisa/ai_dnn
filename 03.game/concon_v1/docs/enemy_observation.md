# 経路モデルへの敵情報

経路モデルの入力末尾に次の2項目を追加しました。

- 敵を視認している: 敵視認時の停止処理と同じ判定。射撃可能な敵がいる場合も1。
- 射撃できる敵がいる: 既存の射線・スモーク・遮蔽判定で射撃対象を選べる場合に1。

`ConconAttackerRouteController.policy_inputs` が、キャラごとのIQ知覚の
敵リストから両方を計算します。学習時の行動選択・次状態の観測・本番の
推論が同じ処理を使います。位置不明の敵は判定から除外します。
準備フェーズと敵なしのroute環境では両方が0になります。
従来の経路・味方・時刻の入力位置は維持しています。

入力数は A1/A3 が28から30、A2が29から31に増えました。
以前の入力数で学習したモデルはロード時に拒否します。
`concon_v1` で学習を停止し、従来と同じ学習コマンドを再実行してください。
学習は新規モデルから開始します。旧モデルを削除する必要はありません。
既存bestが非互換の場合、学習スクリプトはバックアップして選定対象から除外します。
本番で使用するマップの再学習済みモデルを用意してください。

敵視認時の2 tick停止は、従来どおり学習と本番に共通する固定処理です。
モデルが選んだWAITとして登録しません。
