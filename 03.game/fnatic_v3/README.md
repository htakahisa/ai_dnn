# Fnatic v3

新しいルールベースFnatic AI用の設定です。

## 設置・解除阻止マップ

Ghost Championsの現在の設定をコピーしています。

| Fnatic用ファイル | コピー元 | 用途 |
| --- | --- | --- |
| `map_data_guard_plant_fnatic.py` | `gc_v1/map_data_guard_plant_gc.py` | 設置位置パターン |
| `map_data_guard_fnatic.py` | `gc_v1/map_data_guard_gc.py` | 設置後の解除阻止位置 |

両ファイルの `NEW_MAZE_STR` を編集してください。座標は `(行, 列)` です。

- `5`〜`9` はパターンIDです。設置マップの数字と、解除阻止マップの同じ数字が対応します。
- 設置マーカーは共通ゲームマップ `map_data.py` の設置可能マス（`2`）に置きます。
- 解除阻止マーカーは歩行可能マスに置きます。壁（`1`）には置けません。
- 基本地形・マップサイズは共通ゲームマップに合わせてください。

Fnatic側で編集してもGC側には反映されません。GC側の変更も自動同期されません。

## 動作

試合画面・Competition・リテイクシミュレーションのAI欄で **Fnatic v3** を選択してください。
アプリを起動し直すと新しい実装が読み込まれます。学習モデルは読み込みません。

- キャリアーは、歩行距離が最短の到達可能な登録設置位置を選び、そこへ移動します。
- 登録されていない設置可能マスでは設置しません。時間不足でも登録位置へ向かいます。
- 登録位置に到着すると、設置完了まで `PLANT` を続けます。
- 設置後はキャリアーを含む全員を、設置パターンと同じ番号のリテイク阻止位置へ割り当てます。
- 割り当ては移動距離を基準に重複を避け、到着後はその位置に留まります。
- 到着済みの味方が通路を塞いで後続が到着できない場合は、両者の担当位置を交換します。
- 候補不足時のみ、登録位置の隣の歩行可能マスで人数分を補います。
- 移動は壁と味方を避けます。一時的に経路が塞がった場合は待機します。
- 自チームの設置位置を共有し、IQによる座標誤差で担当位置が変わることを防ぎます。

## 設置前の隊形

- キャリアーの前衛は、7マス以内の生存者から `Derke → Chronicle → Leo → Boaster → Alfajer` の優先順位で選びます。キャリアー自身と別部隊のミッド担当は除外します。
- 7マスは行・列の差の大きい方で判定します。前方は、選んだ設置位置までの歩行距離がキャリアーより短い位置として判定します。
- 前衛は通常1〜3歩先を取り、キャリアーは前衛を追い越さないように待機・前進します。サイト到着時は前衛が設置マスを通過して奥へ進み、設置マスを空けます。
- 前衛の選出では7マス外やミッド担当を呼び戻しません。対象となる味方がいなければ前衛を選出せず、本隊が近くに揃うのを待ちます。単独の生存者はそのまま移動します。
- ミッドは `Alfajer → Boaster` の順で、生存していてキャリアーでない1人に固定します。担当が死亡した場合は再選出します。両者が担当できない場合、他の選手をミッドへ代用しません。
- ラッシュ・通常進行のどちらでも、ミッド担当は本隊と分かれて中央制圧位置へ移動・待機します。設置後は対応するリテイク阻止位置へ移動します。
- ミッド以外はキャリアー付近で行動します。周囲3歩を目安にまとまり、遅れた味方がいる場合はキャリアーが待ちます。ほかの選手が単独でサイトへ走る行動は行いません。
- スパイク回収も本隊が担当し、ミッド担当を呼び戻しません。

優先順位、距離、ミッド候補位置は `formation.py` で編集できます。ミッド候補位置はGCの中央制圧位置を参考にしたFnatic専用の設定です。
隊形の役割と距離は自チームで共有した位置から決め、敵の観測情報には既存のIQ知覚を利用します。
本隊で待機中のフラッシュ・リコン・スモークと守備は、既存Fnatic v1の基本ルールを利用しています。

## 向きと自動エイム

攻守ともに、毎Tickの射撃判定前に、射線が通る最も近い生存敵へ自動で向きます。
設置後は射線が通る解除中の敵を優先します。射線は壁・スモーク・途中の生存プレイヤーで遮られます。
リコンで検知中の敵やスモーク越しに撃てる覚醒状態には、通常の射撃と同じ例外を適用します。
AI側の向き指定も有効です。設置前は敵が見えれば敵、見えなければ設置目標を向きます。
設置後は敵が見えれば敵（解除中を優先）、見えなければスパイクを向きます。
ミッド担当は敵が見えなければ中央の進入方向を向きます。
撃たれた次のTickに相手へ向く共通処理も有効です。
