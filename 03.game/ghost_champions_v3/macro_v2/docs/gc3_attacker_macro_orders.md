# アタッカーマクロv2の指示

マクロはアタッカー側で毎tick判断し、次の11個の出力を確率分布からサンプリングします。同じ候補を再選択すれば維持、別の候補を選べば切り替えです。サイト変更やラウンド終了を待たずに変更できます。

| 出力 | 数 | 選択肢 |
| --- | --- | --- |
| プレイヤーの目的地 | 生存しているプレイヤーごと、最大5 | 専用マップで5を置いた座標 |
| チームの設置予定マス | 1 | 両サイトの実際に設置できる座標 |
| プレイヤーへの指示 | 生存しているプレイヤーごと、最大5 | 待機 `WAIT`／進軍 `ADVANCE`／撤退 `RETREAT` |

撤退はユーザー指定により、指定候補へ進む指示よりも優先して本人のラウンド開始時のスポーンへ戻る意味です。帰還先は自チームの公開されている初期配置から保存します。

目的地候補と指示はプレイヤー別に選択でき、5人で同じ候補を共有することもできます。死亡・存在しないプレイヤーには指示を出しません。各出力の確率と合計log probabilityを保持し、PPO評価時も当時の公開履歴と当時の指示で再計算できます。

## 編集するマップ

`gc3_map_attacker_destinations.py` の `MACRO_DESTINATION_MAP_STR` を編集します。

- 0：道。
- 1：壁。ゲーム本体の壁と一致させます。
- 2～4：これまで通りの表示用番号。
- 5：各プレイヤーの目的地候補。
- 6：表示用の警戒候補。マクロの目的地には使いません。

壁・サイト・スポーンを含む編集用マップをコピーしています。元マップにあるオーブ等の5は0に置き換え、目的地候補はまだ配置していません。使いたい通行可能マスを5へ変更してください。候補が0個の場合は、勝手に座標を補わず、設定を求めるエラーで停止します。

設置予定マスは、マクロ用マップの表示番号から推測せず、ゲーム本体で設置可能なマスから選びます。候補を限定したい場合だけ、同じファイルの `PLANT_CANDIDATE_COORDINATES` に `(行, 列)` を列挙します。空のままなら両サイトの全設置可能マスです。座標は0始まりで、最上段が行0、左端が列0です。

候補マップと設置候補のハッシュを持ちます。候補を変更した後に、変更前の学習済みマクロを同じ候補設定として使うことはできません。

## ミクロへの渡し方

各プレイヤーの設置前ミクロへ、本人の目的地・指示と、チーム共通の設置予定マスを追加入力として渡します。目的地と設置予定マスについては、壁を考慮した歩行距離と各移動先での距離の変化も入力します。設置予定マスから目的サイトも設定するため、ミクロ自身のサイト選択は二重に行いません。

指示はミクロの学習入力です。待機による移動マスクの強制、指定座標への強制移動、BFSによる行動の置き換えは加えません。回収・設置・アビリティ等の具体的な行動は、ミクロが物理的に合法な行動から確率的に選びます。目標マスに完全一致する動きを強制しません。

ST100,175で終了した既存ミクロには、この3種類の指示を学習させていません。新しい入力層は初期状態ではゼロ出力なので、既存ミクロを変換しただけで指示を守れるようになるわけではありません。[追加学習の手順](gc3_attacker_micro_directive_training.md)で、既存の重みを保持しながら指示入力層を学習できます。

`DirectedMicroPolicy.fresh()` は重みを読み込まずに初期化します。`from_micro()` は明示的な変換のためのAPIで、自動実行しません。変換時は既存の動きを保持し、新しい指示入力は未学習として記録します。学習済みマクロの読み込みには、指示入力を学習済みのミクロが必要です。

設置後は既存のガードモデルをそのまま使い、新しい目的地・設置予定マス・指示を渡しません。マクロ自体は設置後も判断しますが、この3種類の出力を既存ガードへ反映する処理はありません。

## 保存と既存学習

公開履歴は省略せず、各マクロの選択とミクロに渡した指示を保存できます。現在の判断には過去の履歴と直前の計画だけを使い、今回選んだ出力や未来のイベントを判断前の入力には使いません。

新しい機能は `macro_v2/` に分離しています。v1のマクロの重みは出力構造が違うため読み込めません。通常ゲームのGC v3への切り替えは行っていません。既存のモデル・ログ・教師データを書き換えず、学習も開始していません。

マクロの報酬は既存の指定どおり、キル+1、デス−1、設置+10、勝敗±30、実際に設置して勝利し、相手が一度も解除を始めていない場合だけ追加+10です。ミクロの指示対応追加学習では別途、指示に従う小さな個人報酬を使います。マクロ側の報酬を変更するものではありません。
