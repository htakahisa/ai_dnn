# 指示対応ミクロの調整（v2 run）

**この文書は旧random指示のv2 runの説明です。現在は[簡単なマクロロジックのv3 run](gc3_attacker_micro_simple_macro.md)を通常設定にしています。**

マクロ指示を入力し、ミクロが確率分布から行動を選ぶ構造を維持します。実行時に指示で合法行動を削ったり、経路を強制したりしません。学習はスクリプトを実行した場合だけ開始します。

`gc3_train_attacker_micro_directives.py` 冒頭の名前付き定数が通常設定です。`DIRECTIVE_CHECKPOINT` は調整前の `attacker_micro_directives_v1/best.pt`（ST118607）を引き継ぎます。`INITIAL_CHECKPOINT` は基礎ミクロの固定参照モデルで、指示入力をゼロに戻すためには使いません。基礎ミクロの重みが一致しないモデル、異なる候補マップのモデルは受け付けません。元モデル・元ログを上書きしません。

## 変更内容

- 接近報酬の上限係数を1から4にし、逆行は歩行距離1マスにつき−0.10、到達は+0.5。接近の最高記録と到達ボーナスは、個人・指示・目的地ごとにラウンド内で保持し、往復や同じ指示の再発行で繰り返し加点しません。
- 待機は+0.03、移動・移動要求は−0.10。壁や味方に阻まれた移動要求を待機扱いしません。
- PPOに指示の補助損失（係数0.5）を追加します。公開観測の壁と物理的な合法行動から、待機・目的地への接近に沿う**すべての行動の確率の合計**を高めます。単一の正解ルートには固定しません。3指示の損失を均等に集計し、待機だけの改善に偏らないようにします。
- 接近できる隣接マスが味方などで塞がっていれば、接近の補助損失と接近率の分母から除外します。設置可能・オーブ回収可能・回収中・設置中の判断も補助損失から除外し、設置等を強制キャンセルさせません。公開観測で敵位置が判明している判断では、補助損失の重みを0.25に下げます。回収・設置・戦闘・勝敗の従来報酬は継続します。
- 基礎ミクロと設置後モデルは固定し、指示入力層だけを更新します。固定criticで新しいreturnを当てるために指示入力を歪める回帰損失は外します。固定ミクロへのKL係数は0.10から0.02に下げます。
- 練習用指示は最初の20tickを進軍にし、その後は40tickごとに待機20%・進軍50%・撤退30%でサンプリングします。スポーンにいるままの撤退だけでなく、外へ出てからの撤退も学習対象にします。目的地はユーザーの5の候補だけを使います。
- bestは「実行可能時の指示対応率の最低値→3指示の平均→勝率→設置率」の順で選びます。進軍・撤退の接近率は目的地に未到達で合法な接近が可能な判断を測ります。到達後の停止やスポーンでの停止を接近成功に数えません。3指示とも75%以上かつ測定対象が存在する場合だけ `instruction_ready=True` とします。`directives_trained` は更新履歴であり、習得保証ではありません。

## 実行

作業ディレクトリは `D:\git\ai_dnn\03.game\ghost_champions_v3\macro_v2` です。

```powershell
Set-Location D:\git\ai_dnn\03.game\ghost_champions_v3\macro_v2
python gc3_train_attacker_micro_directives.py
```

既定は追加20,000判断、ST118607→138607です。新しい `data/attacker_micro_directives_v2/` と `logs/attacker_micro_directives_v2/` に保存します。途中再開は同じスクリプトの `RESUME=True`、追加延長は `ADDITIONAL_TRAINING_STEPS` をこのrunの累計追加判断数へ増やします。学習設定・マップ・入力モデル・ソースの変更時は新しい `RUN_NAME` が必要です。

グラフは別のPowerShellで同じ作業ディレクトリから実行します。

```powershell
python tools/gc3_watch_attacker_directive_metrics.py
```

既定は調整後v2で、5秒ごとに自動更新します。右下には勝率と3指示の実行可能時の対応率を表示します。調整前v1は明示的に選択した場合だけ表示します。通常の実戦モデルやマクロモデルの学習は自動で切り替えません。
