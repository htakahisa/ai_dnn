# フラッシュ到達増加と勝利数減少の調査（2026-10-17）

私は、frc_v1 相手の候補モデルについて、追加の学習をせず、既存の重みを固定して原因を調査した。私は、ゲーム本体、AIの行動処理、通常対戦で採用されているモデルを変更していない。

## 比較条件と再現性

診断処理は、保存済み比較と同じseed 100020～100029、各12ラウンド、合計120 attacker ラウンドを使用した。診断処理は、ゲームの処理を呼ぶ前後に計測を追加し、AIへ教師情報を渡していない。私は、現在のモデル71勝・候補68勝と、元の評価の全アビリティ使用集計が両条件とも完全一致することを確認した。

診断処理は、FLASH・SMOKE・RECONのどれについて現在のアドバイザーを使い、どれについて候補のアドバイザーを使うかを切り替えた。各条件は試合開始時に同じseedを設定するが、行動が変わった後の位置・向き・射撃・乱数の消費順序・後続ラウンドは変わり得る。以下の結果は、この10試合での比較であり、独立した追加seedによる確証ではない。

## 重複フラッシュの仮説

ゲーム本体は盲目時間を加算せず、`max(現在の残り時間, 10)` に更新する。私は、爆発の直前と直後の敵の盲目時間を比較した。以下の集計は、carry・escortだけでなく、attacker の全フェーズのFLASHを含む。

| 計測項目 | 現在のモデル | 候補 |
| --- | ---: | ---: |
| 敵に届いたFLASHの爆発 | 118回 | 196回 |
| 敵には届いたが盲目時間の追加がゼロだった爆発 | 0回 | 0回 |
| 新規に盲目にした敵の延べ人数 | 106人 | 167人 |
| すでに盲目の敵に届いた延べ人数 | 24人 | 39人 |
| 敵ごとの盲目時間の追加量の合計 | 1,215 tick | 1,912 tick |
| 盲目中の敵の撃破 | 31人 | 43人 |

私は、今回の差を「同じ敵への重複を有効回数として数えただけ」では説明できないと判断する。追加効果ゼロの重複を区別していなかった元の評価の欠点は存在するが、今回の再現対戦では、その重複が勝利数減少の主因だったという証拠は得られなかった。

敵は盲目でも射撃できる。ゲーム本体は、盲目中の射手の命中率とヘッドショット率を0.1倍にし、射撃自体は止めない。また、アビリティを使ったtickでも射撃処理は実行される。私は、「投擲中は射撃できないから負けた」という仮説をコード上で否定した。

爆発時点で、攻撃射線・向きなどの条件を満たす味方がいなかった爆発は、現在のモデルで101/118回、候補で168/196回だった。この判定は爆発時点だけを見ており、その後の射撃不能を意味しない。私は、候補の盲目中の敵への射撃と撃破が増えたことも確認しているため、全フラッシュを追撃不能だったと扱わない。

## アビリティ別の切り分け

| 候補のアドバイザーを使用する種類 | 現在のアドバイザーを使用する種類 | 勝利数 |
| --- | --- | ---: |
| なし | FLASH・SMOKE・RECON | 71/120 |
| FLASH | SMOKE・RECON | 73/120 |

| FLASH・SMOKE | RECON | 78/120 |

私は、今回の比較では、FLASHだけの変更が勝利数を下げなかったことを確認した。FLASHにSMOKEまたはRECONの片方だけを組み合わせた条件でも、勝利数は71勝を上回った。一方、3種類すべてを組み合わせた候補は68勝だった。したがって、私は、フラッシュの到達数だけを勝利数低下の説明に使うことも、SMOKEかRECONのどちらか一方を単独の原因と断定することもできない。

現在のモデルから候補への敗北内訳は、設置前の全滅23→26、解除負け14→15、時間切れ12→11だった。候補の敗北増加は、盲目中の敵を撃破できていないという一つの数字では説明できない。

## 同じ初期状態から勝敗が分かれた具体例

私は、seed 100029の第1ラウンドを、FLASH・RECONは両方とも候補に固定し、SMOKEのアドバイザーだけを現在のものと候補で切り替えて記録した。両条件は同じ初期状態から開始した。

1. 現在のSMOKE判定を使った条件では、味方はtick 39に位置 (9,33) から (8,32) へSMOKEを使った。
2. 候補のSMOKE判定は、同じtick・位置からの (8,32) の使用を、スコア約0.00998で温存した。味方は次のtickに (8,33) へ進んだ。候補側の最初の盤面差はtick 40で確認できた。
3. 候補側の味方は、その後tick 43に (7,39) へSMOKEを使用した。両条件では、煙の場所・時刻、味方の移動・向きが変わった。
4. 現在のSMOKE判定を使った条件では、味方のFLASH担当がtick 51～53に停止してArlecchinoを射撃し、記録された命中確率は約98%、100%、100%だった。味方は3発を命中させ、Arlecchinoを撃破した。
5. 候補のSMOKE判定を使った条件では、同じ担当がtick 50・52・53に移動射撃を行い、命中確率は約25%、25%、33%だった。味方はこれらの射撃を外し、Arlecchinoはその後も生存して味方を撃破した。
6. 現在のSMOKE判定を使った条件は、最終的にdefender全滅で勝った。候補のSMOKE判定を使った条件は、最終的に解除されて負けた。両条件のこのラウンドでは、敵に届いたFLASHは0回だった。

私は、この例で「フラッシュの改善とは別に、SMOKEの使用・温存による位置・向き・射撃機会の変化が勝敗を変える」ことを確認した。私は、(7,39) の煙そのものが全敗因だったと断定しない。最初の分岐後には複数の行動と乱数消費順序が変わり、現在の記録では、その影響すべてを一つの投擲へ分離できない。

## 調査から判断できる範囲

私は、候補のFLASHの追加効果が実際に増えたことと、全体候補ではSMOKE・RECONも同時に変わり、移動・向き・戦闘の進め方が変わったことを確認した。今回の比較では、FLASHの変更単独で勝利数が下がったという結果は得られていない。フラッシュの到達数増加と、全種類を変更した候補の勝利数減少を、同じ効果の増減として説明した以前の説明は不十分だった。

私は、今回確認した78勝の混合条件も、同じ評価seedを見た後の候補であるため、直ちに採用していない。安定した勝率差を判断するには、独立したseedでの確認が必要になる。私は、今回、通常対戦のモデルと学習処理を変更していない。
