# escort停止条件の変更案は撤回（2026-10-16）

目的は、frc_v1に対してomoko_v1の攻撃ラウンド勝率を改善すること。

接敵時の一律停止を「射撃可能な非失明の敵がいるときだけ停止」に変更した案は、
同条件の6ラウンド対照で修正前3勝3敗から0勝6敗に悪化した。設置数は双方5回。
能力判定モデルなし、seed=100000、既定編成、攻守交代なしで比較した。

悪化が観測された案を採用状態で残した判断は誤りだった。
この停止条件の変更と、その動作を期待するテストは撤回し、
`ov1_learning_attacker_escort.py` は変更前に復元した。

「モデルの移動を実行できる」「射線判定が正確」「単体テストが通る」ことは、
攻撃ラウンド勝率を改善した根拠にならない。今後の候補は修正前との対照で評価し、
悪化が観測された案を改善済みとして採用しない。

別途依頼されたcarryのおもこの覚醒中退避は、この撤回には含めない。
その勝率への効果は未検証であり、改善済みとは扱わない。
