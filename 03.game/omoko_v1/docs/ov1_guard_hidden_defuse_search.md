# 未発見の解除者を探すときの死角への回り込み

2026-10-16。設置(9,3)、解除者(8,4)、煙なし、味方3人生存の解除負けを修正。

## 原因

`competition_results/series_Omoko_Gaming_vs_Furina_Classic_10-1_20261016_074648.json`
の第3試合3・12ラウンド、第5試合7ラウンドなどで確認。スパイク(9,3)へ到着して旋回するだけになり、壁(9,4)の角が遮る(8,4)を確認できなかった。

## 変更

実戦の窓口`ov1_attacker_controller.py`から、`ov1_inference_team_tactics.search_hidden_defuser`を呼ぶ。
公開解除通知があり、解除者がまだ未発見の場合に限り、設置マスの周囲1マスにある歩行可能セルを調べる。
視界内で確認済みの候補を解除進行中だけ記憶し、未確認の死角へ射線が通る最寄りの位置へBFSで回り込む。
同じ距離では確認できる候補が多い位置を優先する。(9,3)到着を探索終了条件にしない。
解除者が発見されたら既存の解除阻止射撃へ移行する。解除通知がなくなる、対象が変わる、解除進捗が戻る、ラウンドが変わる場合は探索をリセットする。

経路と仮想射線に使う占有は味方と公開済みの敵だけ。非公開の敵座標は参照しない。
高速移動でも角や確認位置を通り越さないよう1歩に制限する。公開ダメージ領域への進入回避とルールによる強制向きを維持する。

## 検証と限界

`test/test_ov1_hidden_defuse_search.py`は実マップ、IQラッパー、本番移動・射撃・解除完了処理を使用する。
ねこさん(10,2)、いぬさん(13,3)、ひつじさん(13,7)、Lohen(8,4)、設置(9,3)、煙なしを再現。
旧処理ではHP20の相手にも6tickで解除されることを確認し、修正後は(8,3)へ到達して射撃することを検証する。

射撃乱数を変えた100回ずつの局所比較では、6tick以内の解除阻止は次の結果だった。

|解除者の開始HP|旧処理|修正後|
|---|---:|---:|
|20|0/100|100/100|
|70|0/100|98/100|
|100|0/100|96/100|

これは局所状況の検証であり、試合全体の勝率比較ではない。テスト用エンジンでは試合全体のコンボ・覚醒更新は再現していない。
射撃乱数を固定したテストは経路・射撃接続の確認に使い、実戦で必ず命中することを保証しない。

観測次元、行動数、モデル、壁判定規則、学習シナリオは変更していない。この修正のための再学習は不要。
定点アドバイザーが署名対象にしている各フェーズの推論ファイルも、この修正では変更していない。
実行中のゲームにはコード変更が反映されないため、ゲームを再起動する。
