# FRC plantの時間切れ調査と修正

2026-10-10。学習・重み更新は実行せず、保存bestの教師・探索なし評価、公開行動診断、単体テストで調査した。

## 再現結果

version 5のFRC best（set 60、SHA256 `6ac1a1b3170c7ae9f684f5fbe479738c52f99331fd29bb8583aea9fd4ecda025`）を保存時と同じTouyama編成・seed `804000042` / `804000142` / `804000242`で評価した。元の実行条件で36ラウンド中13回設置（36.1%）、無傷条件の設置8回（22.2%）、失敗23回は全て時間切れ。失敗時も平均約3.8人生存していた。

原記録は `logs/attacker_plant_review/frc_v1.json`。追加の1seed診断は `frc_v1_detail.json`。無傷条件は5人生存・開始時チーム最大HPの90%以上で変更していない。

## 確認した問題

1. 経路の同じ辺を往復2回すると、その経路を選び直すまで移動を禁止していた。運搬役が(11,32)から目標へ進めず、同じ位置で教師までSTAYになる例を確認した。1seedの敵接触なし運搬役STAYは278件、うち211件は距離を縮める合法移動がなく、67件は合法前進があるのにSTAYを選んでいた。全ての停滞を辺制限だけに帰属させるものではない。
2. 全36ラウンドで教師の移動を無視してSTAYした場面1778件。設置可能なのにPLANT以外を選ぶ場面24件。58候補を同等に学習するだけでは、少数の運搬役経験と「何をするか」が薄まる。後者は学習上の仮説で、新学習後の独立評価で確認する。
3. アビリティ121使用のうち、監査上の敵への効果・遮断射線が記録されなかったもの86件。観測されなかった効果もあるため、全てを無駄使用とは断定しない。射撃216回のうち移動中114回で35命中、停止中102回で92命中。死亡43件中38件で味方の援護射線なし。複数射線・停止射撃・効果のある能力使用を維持して学習する必要がある。
4. サイト内で始まる候補経路が、入口の外側と内側を同一マスとして別入口隊へ割り当てる場合があった。サイト外→サイト内の隣接した異なる2マスだけを有効とする。
5. ユーザー提示の「右上に自キャラ、左下に敵、右列下2マスが壁」では、旧Bresenhamの壁判定は自キャラ→敵で通過、逆向きで遮断。壁の角を取りこぼす実エンジンの不具合を再現した。青い点線の丸はリビール表示で、任意の自キャラから射撃可能という意味ではない。リコンや別の味方による視認でも表示される。

## 修正

- 辺の移動制限を直近8tickの範囲に限定。公開交戦・失明・退避は対象外。移動予約と地形の合法性は保持する。
- 合法PLANT・合法前進の有無をモデルへ渡す。運搬役の不要STAYには学習費用を付け、戦闘、設置中、教師の合流/フラッシュ待ち、合法前進不可は除外する。
- Toru v4の `tv4_train_retake.py` の行動種類損失と解除担当者の経験混合を設置役に適用。FRCは行動種類損失1.0、設置役経験65%、更新400回/セット（通常200回）。他相手は種類損失0.25・設置役50%。向きの教師損失も残す。全員の経験を捨てない。
- 無効な別入口割当を除去。停止射撃、複数射線、能力効果、低被害設置の入力・教師・報酬は保持する。推論で能力や設置を強制しない。
- 壁判定は中心間の線が触れる全マスを調べるsupercoverへ修正。共通エンジンの射撃/視認、v3の公開戦闘判断、高速の公開視界計算で揃える。弾道表示・投射経路のBresenhamは変更していない。
- plant version 6、入力628。共通LOS版をv3のscenario署名へ追加。旧モデル・旧ケースとの再開混在を拒否する。Toru固定対戦相手は保存モデルと同じ初期監視位置を保持し、実行時LOSは修正版を使う。両側の固定bestが読めることをテストした。
- 各評価ラウンドをset・seed付きJSONLへ保存する。replayのランダム参照は一度listへ変換し、担当者抽出も更新ごとではなくセットごとに行う。

## 性能についての限界

旧重みで移動制限だけを直すと6/36（16.7%）。さらに壁判定を修正した旧重みの診断では12/36（33.3%）、無傷5/36（13.9%）。後者は無効な別入口割当除去の追加前に評価した。これらは新モデルの性能ではなく、旧入力の追加2列をゼロ重みで拡張した読取専用比較。診断変換は本番読込へ適用せず、モデルも保存していない。修正だけで旧bestが改善したとは言えない。

改善した学習性能の確認には再学習が必要。学習禁止の指示に従い、ここでは実行していない。設定と順序は `tv3_usage.md` を参照。FRCのattacker analysis→plantを新規学習し、教師・探索なしの同一36ラウンドで設置率・低被害設置率・時間切れ・生存・能力効果を比較する。その後は異なるseedでも確認する。守備系モデルも共通LOS修正に合わせて順番に更新する。
