## best選定は予測誤差を強く制約していない

採用checkpointのランダム経路評価のBrierは0.340602。二値成功ラベルに常に50%を返せば0.25であるため、この予測指標では固定50%より悪い。Brier skill `1-Brier/0.25` は約-0.3624。

`best_rank()` は生存条件付き設置率→設置率→生存→被害→使用→時間→Brierの辞書式比較。実力評価が少し上がれば、Brierが悪くても前の評価より高順位になる。予測が信頼できることの保証はない。

今回は `prediction_metrics()` に `constant_half_brier` と `brier_skill_vs_constant_half` を追加し、通常の評価ログへ両者を出すようにした。前回追加した入口別・高信頼群の評価と合わせ、全体の設置率と予測の信頼性を別々に確認できる。best選定の変更、50%への強制補正、危険入口の強制排除は採用していない。未検証の閾値で別の性能低下を導入しない。
