# 被リコン時の煙越し危険判定の修正

新しいplant v13に実装。被リコン中は煙による遮蔽を敵からの射線に適用しない。味方から敵への射線は別に計算する。入力は現在の公開視認と最大20tickの有効な記憶のみ。敵の実座標・向き・失明状態を非公開情報から取得しない。射撃できる可能性の判定であり、実際の命中率ではない。

- 移動先ごとに、敵からの射線数・こちらが撃ち返せない射線数・退避の最初の一歩を入力する。被リコン残時間、遮蔽経路の有無と距離も追加。
- 被リコン時の教師は最大12歩で壁の遮蔽へ到達する経路を探索する。途中で既知敵からの射線数を増やさない。最初の一歩はエンジンの合法移動マスクと照合し、公開味方・公開敵の占有セルを避ける。サイト外からの退避ではサイト内へ踏み込まない。
- 壁陰から危険な射線へ出ようとする場合は、その場で待つ例を教える。被リコンが切れた場合、安全な移動、敵情報がない場合、古い／死んだ／見えて空の記憶にはこの退避を適用しない。
- 射撃支援・集合待ち・無関係な投擲で退避教師を上書きしない。推論の行動はDQNが合法行動から選ぶ。退避を強制する新しい行動上書きは追加しない。

右下オーブ座標へ固定しない。実マップの(11,40)、既知敵(2,40)、煙(8,40)ではサイトに入らず壁陰へ逃げる教師例を確認した。別の一本道の例では、旧3歩探索では届かない9歩先の壁陰へ向かう最初の合法な一歩を確認した。これは公開snapshotの制御されたテストであり、学習済みモデルの実対戦改善を証明するものではない。
