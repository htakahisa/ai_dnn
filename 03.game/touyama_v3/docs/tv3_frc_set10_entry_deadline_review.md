# v16 best set10：人数有利の時間切れの調査

学習は実行せず、保存best v16 set10 / analysis v4 set50をstrictに読み込んだ。seed804000142の失敗を、通常の評価と同じ独立ラウンドブロックで再現した。モデルは行動を選ぶ。教師・探索は0。保存bestとlatestは変更していない。

## 第8ラウンド：味方が入口を塞ぐ

対照は100tickで時間切れ、5v2、残HP460。保持者は11,40で10,40への進入を待つ。10,40の味方slot4は10,42を目標とするが、途中の10,41を味方slot2が占有し、8,40にも味方slot3がいる。

壁だけの目標距離は2歩、味方を避けると16歩。teacher_distancesは4歩を超える余分な迂回を採用しない。最短方向は味方で禁止され、教師もモデルも待機を選ぶ。この状態が65tickから終了まで続いた。

候補v17は、保持者の現在の目標を塞いでいるサイト内の味方について、その味方自身の目標が到達不能または迂回過大なら、4歩以内で届く空いた同サイト内の目標へ変更する。63tickにslot4の目標を10,42から9,40へ変更すると、モデル自身がNを選んで入口を空けた。69tickに5v2、HP460で設置。移動を強制した結果ではない。

変更はhelper endpointに保持し、ルート変更時には通常の再割当へ戻る。保持者自身、入口を塞がない味方、通常の目標に届く味方、近くに空いた到達可能なサイト地点がない場合は変更しない。

12ラウンド連続比較では設置9→8。72ラウンドでは設置59→58、人数有利45→46、人数同数以上51→50、時間切れ11→12。局所の詰まりは直ったが、全体の改善ではないのでv17は採用せず、保存v16を維持した。連続比較には修正後の試合・乱数の蓄積変化も含まれる。

## 第23ラウンド：経路候補が空になり、設置可能でも行動計画が消える

同じseedでstart_round=13、対象23を再現。対照は4v2、HP360で時間切れ。94tickに保持者は設置可能な10,40に入り、Eを選んで95tickに10,41へ移動した。残り5tickで全員の行動計画が空になり、終了まで新しい判断を作らなかった。

候補生成は移動＋4tick設置＋5tickの余裕を要求する。通常の候補も残存ルートもないとplannerがNoneを返すため、設置可能な現在位置でも余裕不足で計画を作れなくなる。

候補v18は、通常の候補と残存ルートがすべて空の場合だけ、余裕の5tickを外して候補を再生成する。移動＋設置の実時間内の条件は残す。通常候補がある場合は変更しない。analysisの学習データ収集は元のplanner設定のまま。

対象前の結果・開始時乱数hashを照合した比較では、96tickからモデル自身が4回連続でPLANTを選び、100tickに4v3、HP360で設置。追加行動を入れたため敵人数は元の時間切れ時と異なる。設置を強制した結果でも、余裕のない候補を必ず成功させる保証でもない。
