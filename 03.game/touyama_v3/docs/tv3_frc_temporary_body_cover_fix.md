# 味方の一時的な遮蔽：実装と再学習前の確認

plant v16の候補として修正。通常の `PLANT_VERSION` は13を維持する。モデル・学習データは変更しておらず、重み更新は0回。

## 修正内容

- 連続tickの空マス確認と、幾何学的視界を分離するv15の修正を含む。
- incomingの危険特徴量では、動ける味方の身体だけで遮られた射線を「味方が離れた場合の被射線」として数える。現在移動不能かつワープ中でない味方は、そのtickの遮蔽物として残す。壁・スモークの扱いは変えない。
- 実際に撃ち返せるかの判定は現在の身体遮蔽を保持する。「味方が離れた場合にも撃ち返せない」特徴量は、入射・返射とも同じ仮定を使い、味方の遮蔽だけで一方通行と誤認しない。
- 教師は将来の危険を能力準備の条件に含める。味方が動く可能性だけで無期限の待機を教えない。被リコン時の壁退避は保持する。
- モデルの行動を前進・退避・能力使用へ強制する処理は追加していない。v14の全面的な前進復帰も含めない。

schemaで入力の意味と教師の変更を区別する。旧v13の読み込みは旧schema・旧実行経路のまま。将来v16を学習する場合、同一の盤面・LOS・入力構造・analysis依存のv13重みだけを初期値にできるが、旧optimizer/replayは再開しない。この初期化は通常のcheckpoint互換性を意味せず、保存版の書き換えは行わない。
