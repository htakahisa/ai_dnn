# 時間切れと設置品質の報酬修正（効果は未検証）

目的は、時間切れを引き延ばすほど罰が弱くなる構造を除き、どの設置にも正の終端報酬を与え、人数関係・残りアビリティで品質を区別すること。報酬は勝率の代用指標であり、新しい学習済みモデルで性能が上がったとはまだ言わない。

## 設置報酬

終端報酬は `1 + 8 × 味方生存 / (味方生存 + 敵生存) + 0.1 × 残りアビリティの味方割合`。アビリティは生存者の通常チャージ数で、敵の残量は評価ラベルとしてのみ読む。1v5も正の設置報酬。5人生存・HP90%以上の特別加点と、人数を二重に数える絶対生存数加点は廃止。被ダメージ・死亡の行動中ペナルティは別に残るため、ラウンド累積報酬が必ず正になるという意味ではない。

同じアビリティ割合0.5で、1v5=2.3833、3v4=4.4786、3v2=5.85、5v5=5.05。人数比を第一にし、同じ人数比のときに残りアビリティを比較する。5v5の可能な人数組合せを全列挙し、アビリティ加点が良い人数比を逆転させないことをテストした。人数比が実際の設置後勝率と同じとは仮定しない。HP、位置、能力種別、残り時間の実際の価値はこの式だけでは表現できない。

設置前に敵が全滅して実際に勝った場合も、設置できなかった失敗として罰しない。

## 時間切れの先延ばし

- 生存者の時間切れは基準−10、その他の設置失敗は−6。
- 失敗終端の値を、そのキャラクターの連続した記録行動数Nに応じて `GAMMA^(N−1)` で割る。GAMMA=0.98なので、終端成分をその行動列の最初まで割り引くと常に−10/−6となる。20行動後でも100行動後でも、失敗を遅らせて終端罰を薄められない。
- 既に死んだキャラクターには、生存者の後の待機による特別な時間切れ罰を付けず、一般失敗−6を自身の行動列に対応させる。成功の後付け報酬も与えない。
- 正当な戦闘・退避・短い連携待ちを、無条件でSTAY減点する変更は入れない。機械的に待機しか合法でない場合、報酬を強くしても動けるようにはならない。

これは終端成分の数学的整合性であり、全ての密な途中報酬やモデルの予測値まで同じになる保証ではない。終盤の即時罰の絶対値は大きくなるため、学習の安定性・無理な突撃・能力使用・必要な退避への影響を新しい独立評価で確認する必要がある。

## 互換性と初期値

観測と行動のschemaはplant v13のまま。報酬と失敗補正の設定を保存configに含め、旧rewardのoptimizer/replayをそのまま再開することは拒否する。現在のbest/latestは書き換えていない。

`tv3_train_attacker_plant.py` 冒頭の `WARM_START_FROM_BEST=True` により、schema・analysis hash・相手AIが一致するbestの重みだけを新しい学習の初期値にできる。元のbestファイルのバイト列とSHAを `data/attacker_plant/warm_start_sources/<opponent>/<hash>.pt` へ保存する。新しいoptimizer/replay、0からのset数で始め、warm_start_hashで出自を記録する。過去90セットを新報酬で学習したと偽らない。互換性がなければ新規初期化し、その理由をログに出す。

保存bestの評価に新しい選定指標・敵の能力残量がなければ、同じ評価条件で再評価してから比較する。モデルhash・config・seed・選定規則の一致する再評価結果はキャッシュし、同じ再評価を繰り返さない。新たなモデルの評価checkpointも保存する。

作業ディレクトリは `03.game/touyama_v3/`。通常実行は `python tv3_train_attacker_plant.py`、対象や回数・新規/再開は冒頭定数。これは実行方法の記録であり、現時点で長時間の全対象再学習を推奨するものではない。
